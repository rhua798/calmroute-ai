# CalmRoute AI · 安心领航

> 面向智能座舱的 AI 主动式出行助手。让每一次出发，都有把握。

CalmRoute AI 是一个针对智能汽车导航场景的产品概念项目。它从用户的自然语言出行需求出发，联动地图、充电、停车、餐厅与天气等服务，主动规划行程、预判风险，并通过 AR-HUD、仪表、中控和语音提供清晰、可解释的下一步建议。

## 项目背景

现有导航产品很擅长“把用户带到目的地”，却仍需要用户自己处理多目的地排序、补能、停车、排队和临时路况等不确定因素。

本项目希望验证一个核心命题：

> 导航不应只是被动提示路线，而应成为能够理解目标、持续检查风险、并在恰当时机给出可信建议的出行助手。

## 核心场景

用户周六上午从上海自驾前往莫干山，需要途中接人、补能和用餐，并在指定时间前到达民宿。行程中出现充电站排队，系统需要在不影响抵达时间的前提下主动生成备选方案。

## 核心能力

- **AI 多目的地行程编排**：理解时间、电量、偏好和服务等约束。
- **主动异常处理**：以“发生了什么—影响是什么—建议怎么做—为什么”组织决策。
- **跨屏导航策略**：AR-HUD 负责立即动作，仪表维持驾驶预期，中控承载全局决策。
- **出行确定性指数**：综合抵达时间、电量、排队、停车与天气风险，衡量行程的可靠程度。
- **数据驱动迭代**：通过决策耗时、错过转向率、AI 建议接受率与安全感评分验证体验。

## 产品原则

1. **先给结论**：驾驶场景中先告诉用户要做什么，再按需解释。
2. **建议必须可解释**：展示时间、里程、电量等关键权衡。
3. **在需要时主动，其余时间安静**：以影响程度和紧迫性决定是否打断。
4. **安全优先于信息完整**：将复杂交互留在中控或停车状态。

## 体验指标

| 指标 | 定义 | 项目目标 |
| --- | --- | ---: |
| 复杂路口决策时间 | 看到指引到做出正确操作的时间 | ≤ 3.0 s |
| 出口错过率 | 复杂路口未正确驶出的任务占比 | ≤ 10% |
| AI 建议接受率 | 用户接受主动方案的比例 | ≥ 70% |
| 建议理解率 | 用户能正确复述推荐理由的比例 | ≥ 85% |
| 到达时间误差 | 实际与预测抵达时间的差值 | ≤ 8 min |
| 主观安全感 | 5 分量表的用户评分 | ≥ 4.2 |

> 注：原型中的数据为首轮探索性测试的目标值，不代表已完成的大样本实验结论。

## 技术栈

- React 19 + TypeScript
- vinext / Vite
- CSS 响应式交互原型
- 计划接入：地图路径服务、大语言模型、SQLite 行程数据

## 本地运行

Node.js 需要 `22.13.0` 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
